# company-analysis

企業の公式サイトURLを貼るだけで、就活（新卒・中途）のための企業分析レポートをAIが自動生成するWebアプリです。
**完全無料**で使えるように、Google Geminiの無料枠のみで動作します（クレジットカード登録不要）。

## できること

1. トップページに企業の公式サイトURL（例: `https://www.example.co.jp`）を入力
2. サーバーがトップページと、サイト内から見つかる「会社概要」「経営理念」「事業内容」「採用情報」「ニュース」「IR・業績」「沿革」「サステナビリティ」などの関連ページを自動で取得
3. （任意でWeb検索を設定した場合）同業他社比較・直近ニュース・口コミ・リスク情報などを検索で補足
4. 取得した情報のみを根拠に、Gemini APIが以下を含む構造化レポートを生成
   - 企業サマリー
   - **基本情報**（設立年・資本金・事業所・従業員数）
   - **企業理念・ビジョン・ミッション**
   - **同業他社との比較**
   - **採用情報**
   - **業績の推移**
   - **経営方針の変遷**
   - **主要プロジェクト・注力領域**
   - **今後の展望**
   - **直近ニュース**
   - **企業文化・働き方**
   - **社員の声・口コミ**
   - **リスク・係争案件**
   - **その他の有用情報**
   - 選考対策（志望動機のヒント／想定質問／逆質問アイデア／自己PRとの接続ポイント）
   - 参照した実際のページURL一覧（公式サイト／Web検索を区別して表示）

書かれていない情報は「情報不足」「記載なし」と明記するようプロンプトで指示しており、推測による断定を避ける設計になっています。ただし最終的な事実確認はご自身で行ってください。

## 技術構成

- Next.js 16 (App Router, TypeScript) + Tailwind CSS
- サーバー側スクレイピング: `cheerio`（HTML本文抽出）
- AI分析: `@google/genai`（**Gemini API・無料枠**、JSON Schemaによる構造化出力）
- Web検索（任意）: Google Custom Search JSON API（**無料枠 1日100クエリ**）
- SSRF対策: 取得先ホストの名前解決結果がプライベート/ループバックIPの場合は拒否

## セットアップ（すべて無料）

### 1. 依存関係のインストール

```bash
npm install
```

### 2. Gemini APIキーの取得（必須・無料）

1. https://aistudio.google.com/apikey にアクセス（Googleアカウントでログイン）
2. 「Create API key」でAPIキーを発行（クレジットカード登録不要）

### 3. 環境変数の設定

`.env.example` をコピーして `.env.local` を作成します。

```bash
cp .env.example .env.local
```

```
GEMINI_API_KEY=取得したAPIキー
```

### 4.（任意・無料）Web検索の設定

「同業他社との比較」「社員の声・口コミ」「直近ニュース」「リスク・係争案件」をより充実させたい場合は、以下を設定してください。未設定でも動作しますが、これらの項目は「情報不足」と表示されます。

1. https://programmablesearchengine.google.com/ で検索エンジンを新規作成し、「検索対象」を **ウェブ全体を検索** に設定。発行された「検索エンジンID」を控える
2. https://console.cloud.google.com/apis/library/customsearch.googleapis.com で **Custom Search API** を有効化し、APIキーを発行（**1日100クエリまで無料**、それ以降は課金設定をしない限り呼び出しが失敗するだけで安全）
3. `.env.local` に追記

```
GOOGLE_SEARCH_API_KEY=取得したAPIキー
GOOGLE_SEARCH_CX=検索エンジンID
```

### 5. 起動

```bash
npm run dev
```

http://localhost:3000 を開き、企業のURLを入力して「分析する」を押してください。

### 本番ビルドで動かす場合

```bash
npm run build
npm run start
```

## 制限事項・注意点

- JavaScriptでコンテンツを描画するSPA型の企業サイトでは、本文が取得できず分析精度が下がる場合があります。
- 一部サイトはボットアクセスを制限しており、取得に失敗することがあります（その場合はエラーメッセージが表示されます）。
- Web検索を設定しない場合、「同業他社との比較」「社員の声・口コミ」など公式サイトに載りにくい項目は「情報不足」と表示されます。
- Gemini APIの無料枠にはレート制限があります（詳細は https://ai.google.dev/gemini-api/docs/rate-limits を参照）。制限に達した場合は時間をおいて再試行してください。
- 生成される内容は公開情報に基づくAIの分析であり、正確性を保証するものではありません。就活における最終判断の参考情報としてご利用ください。
